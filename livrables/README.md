# Thư mục livrables/ — Sản phẩm bàn giao & Kết xuất (Outputs)

Thư mục này chứa toàn bộ các sản phẩm hoàn thiện, file kết xuất hoặc báo cáo do AI và hệ thống tạo ra để bàn giao cho người dùng.

---

## Các loại sản phẩm lưu tại đây:
- File kết xuất báo cáo doanh thu, chi phí, kiểm kê kho định dạng Excel/CSV.
- Ảnh chụp màn hình kiểm thử giao diện (visual test screenshots).
- Bản kết xuất schema database hoặc biểu đồ quan hệ thực thể (ERD).
- File thiết kế vector xuất bản.

> **Quy ước**: Đặt tên file theo tiền tố ngày tháng `YYYYMMDD-ten-file` để tiện theo dõi lịch sử kết xuất.
